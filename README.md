# CRDT 购物车分布式存储 Demo

## 项目简介
本项目针对“场景一（购物车并发冲突）”，实现了一个基于 CRDT（无冲突复制数据类型）和版本向量（Version Vector）的高可用购物车存储系统。

## 核心特性
1. 最终一致性：多端并发操作（手机/电脑）在断网恢复后能自动收敛。
2. 冲突解决策略（Add-Wins）：在网络分区期间，若一端删除、一端加购，系统优先保留加购数据，确保用户操作不丢失。
3. 状态持久化：模拟节点突然宕机后，通过本地 JSON 文件恢复状态，保持高可用。
4. 幂等性保证：处理网络消息重复发送的故障，多次合并不会导致数据异常。

## 文件说明
* `crdt_cart.py`：CRDT 核心逻辑与持久化实现。
* `simulate_fault.py`：故障注入演示脚本（包含正常同步、网络分区、节点宕机、消息重复发送四个场景）。
